# Local Development Setup


## Requirements

- Node.js
- MongoDB Atlas Account
- Git


# Backend Setup


Navigate:

cd server


Install dependencies:

npm install


Create .env file:


MONGO_URI=
JWT_SECRET=

EMAIL_USER=
EMAIL_PASSWORD=


Run backend:

npm run dev


Backend runs on:

http://localhost:5000



# Frontend Setup


Navigate:

cd client


Install dependencies:

npm install


Run frontend:

npm run dev


Frontend runs on:

http://localhost:5173
