# Eventiq Project Details


## Description

Eventiq is a full-stack MERN event booking platform that allows users to discover, register, and book events while providing administrators with event management capabilities.


## Features


### User Features

- User registration
- OTP email verification
- Secure login authentication
- Browse events
- Search events
- Book events
- View booking history


### Admin Features

- Admin dashboard
- Create events
- Manage events
- View bookings
- Approve booking requests


## Tech Stack


Frontend:

- React.js
- Vite
- CSS
- React Router
- Axios


Backend:

- Node.js
- Express.js
- REST APIs
- JWT Authentication
- Nodemailer


Database:

- MongoDB
- Mongoose
- MongoDB Atlas


Deployment:

- Vercel
- Render


## Security

Implemented:

- JWT authentication
- Password hashing using bcrypt
- Protected routes
- Role-based access control
